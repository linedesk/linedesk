# Linedesk brand (interim)

The interim logo is **the lit line key**. Desk phones have a key for every line, and it lights up while the line is in use. Linedesk is the line that is always lit. It's a placeholder until we do a proper identity, so expect it to change.

## Files

| File | Use |
|---|---|
| `linedesk-logo.svg` / `.png` | Mark and wordmark on light grounds |
| `linedesk-logo-reversed.svg` | Same on dark grounds (transparent background) |
| `linedesk-logo-on-dark.svg` / `.png` | Same with the dark background included |
| `linedesk-mark.svg`, `linedesk-mark-reversed.svg` | Mark only, 48 px box |
| `linedesk-mark-small.svg` | Mark with heavier strokes for 24–32 px |
| `linedesk-avatar.svg`, `linedesk-avatar-1024.png`, `linedesk-avatar-512.png` | Avatars and profile pictures (GitHub, Google, Slack, Linear): full square on ink, safe for round crops |
| `linedesk-icon.svg`, `linedesk-icon-512.png`, `icon-192.png`, `apple-touch-icon.png` | App icon (rounded square) |
| `linedesk-logo-google-320x132.png` | Google Workspace logo (Admin console, Personalization): logo on ink |
| `favicon.svg`, `favicon-16.svg`, `favicon.ico` | Browser tab. At 16 px the label line is dropped. |

The wordmark is Geist Mono Medium with −0.05 em tracking, converted to outlines so the files don't need the font.

## Rules

- Colours: ink `#1C1917` and paper `#FAFAF8`, the same as the app. The light is `#22C55E` on light grounds and `#4ADE80` on dark ones.
- The light is the only colour in the logo. It means the same as green in the app: live.
- The key can work as a status: grey for quiet, green for a call in progress, red for urgent.
- Leave space around the logo of at least the height of the key.
- Don't put "Open" right before the name.
